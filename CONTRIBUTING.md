# Contributing

Thank you for improving Car Rental Desktop.

1. Keep all source code, identifiers, interface text, tests, and documentation in English.
2. Preserve the existing role and file-persistence behavior unless the change explicitly replaces it.
3. Run `./test.ps1` before submitting a change.
4. Do not commit real personal data, credentials, build output, IDE caches, or local logs.

Please describe the behavior change and its verification in every pull request.
